# 桌宠矿工 · Deep Desk Miner

一款运行在 Windows 桌面上的轻量挖矿养成游戏。原创矿工仓鼠会把日常键盘敲击、鼠标点击和挂机时间转化为挖矿伤害；玩家一路深入 10,000 层矿井，收集五档矿物与宝箱装备，孵化并培养 18 只宠物，搭配三系技能树和 12 套装备效果。

> 本项目借鉴了放置/点击类游戏的成长节奏，但角色、美术、数值、系统与实现均为独立设计；与《点杀泰坦 2》及其开发商无隶属或合作关系。

## 下载与运行

前往仓库右侧的 [Releases](../../releases/latest) 下载最新版本：

| 版本 | 适合谁 | 使用方法 |
| --- | --- | --- |

| 单文件版 `.exe` | 希望只传一个文件的玩家 | 直接双击；首次运行会把游戏文件释放到 `%LOCALAPPDATA%\DeepDeskMiner\App\Build12` |

当前发布包未购买商业代码签名证书，因此 Windows SmartScreen 可能显示“未知发布者”。请只从本仓库 Release 下载，并使用随版本提供的 SHA-256 文件核对完整性。

## 一分钟上手

1. 启动后，仓鼠和当前挖掘目标会出现在桌面右下角。
2. 正常使用键盘或点击鼠标即可攻击；连续 10 秒没有输入后，仓鼠会自动挖矿。
3. 要调整桌宠位置，直接按住仓鼠拖动即可；窗口会自动限制在当前屏幕的可见范围内。
4. 宝箱里的装备和首次到达 70 层倍数获得的技能点会立即保存；矿物价值与宠物蛋要在返回地面后统一结算。
5. 在冒险手册里培养宠物、分配技能、查看装备和战报，然后继续下矿。

## 核心体验

### 桌面输入就是攻击

游戏只接收两类匿名事件：`keyboard` 和 `mouse`。每次有效物理按下都会造成相应伤害，长按产生的系统自动重复与程序注入事件不会被计入。桌宠不会抢占输入焦点，默认点击穿透，日常办公、聊天或浏览时也能持续推进。

- 键盘伤害受镐子、键盘技能、宠物和套装加成影响；
- 鼠标伤害拥有独立倍率与弱点爆破玩法；
- 10 秒无输入后进入自动挖矿，重新输入会触发部分“复工”技能；
- 高频输入只合并视觉动画，不漏算有效伤害；逻辑上限为键盘 30 次/秒、鼠标 20 次/秒；
- 冒险手册的矿井页会同时显示当前键盘、鼠标和挂机单次攻击力。

### 1～10,000 层矿井

前 10 层承担基础教学，此后生命值按连续曲线增长，并在每个百层节点获得额外提升。第 10,000 层设置终局钻石目标。

- 基础生命值：10；
- 每层生命增长：×1.032；
- 每 100 层额外生命增长：×1.35；
- 全程使用 64 位浮点数计算深层生命和伤害，避免 500 层以后出现整数溢出或 Windows PowerShell 重载异常。

### 五档矿物与宝箱

每个品质都有不同名称、颜色、价值、耐久和原创透明贴图。宝箱基础出现率为 15%，最终上限为 60%。

| --- | --- | --- | ---: | ---: | --- | ---: | ---: | ---: | ---: |
| 普通 | 白 | 铁矿 | 1 | ×1 | 木箱 | ×0.8 | 66.5% | 64% | 45% |
| 稀有 | 蓝 | 蓝晶 | 4 | ×2 | 铁箱 | ×1.5 | 20% | 20% | 27% |

| 传说 | 橙 | 太阳金 | 80 | ×8 | 黄金箱 | ×10 | 2.5% | 4% | 6% |

## 收益、返航与战报

矿井中的奖励分为两种结算方式：

| 奖励 | 结算时机 | 说明 |
| --- | --- | --- |
| 装备 | 立即永久结算 | 开箱后立刻进入背包，并触发关键存档 |
| 技能点 | 立即永久结算 | 首次抵达 70 层的倍数时获得 |
| 矿物价值 | 返回地面结算 | 按当前返航比例和资金加成兑换成金币 |
| 宠物蛋/宠物 | 返回地面结算 | 回到营地后进入宠物系统 |

基础返航比例为 70%，鞋子可将其提高到最高 90%。衣服、资金类宠物和特定套装会进一步提高最终金币。返回地面后，系统还会自动比较背包，为四个装备部位换上综合属性最高的物品。

桌宠右下角会实时显示：

- 已获得矿物价值：`XX 金币`；
- 已获得装备：`XX 件`。

点击战报可直接打开冒险手册的“矿井战报”页。桌宠与手册使用同一份实时状态，数据同步更新；返回地面结算后本轮计数清零。

## 三系技能树

首次到达第 70、140、210……层时获得 1 个技能点。游戏会记录最高技能里程碑，返回地面后重新经过已抵达楼层不会重复奖励。技能页支持随时零消耗重置并全额返还技能点。

技能树固定按第 1 层到第 5 层正序展示；前一节点投入 3 点后解锁下一层。

装备背包支持按部位和品质筛选；名称与详情使用白、蓝、紫、橙、红品质色，并显示具体属性、当前装备对比和套装收集进度。游戏不要求手动穿戴：返回地面后会自动装备各部位属性最高的物品。

## 桌宠交互与冒险手册

桌宠窗口透明、置顶，仓鼠和“矿井战报”区域以外默认点击穿透，不遮挡正常桌面操作。界面不再使用悬停工具条；按住仓鼠并移动超过 5 像素即可直接拖动，矿物不会误触拖拽，桌宠也不能被拖出当前屏幕工作区。

冒险手册集中管理：

- 矿井战报与返航收益预览；
- 当前攻击力、楼层、生命和输入状态；
- 宠物孵化、出战、被动效果与升级；
- 正序技能树、投入点数与免费重置；
- 装备背包、分类筛选、属性比较与套装进度；
- 默认开启且可随时关闭的 Windows 开机自启动；
- 存档目录、诊断记录和退出。

关闭冒险手册不会退出桌宠。程序还提供系统通知区域入口，可用于显示桌宠、打开冒险手册、暂停或退出。

## 存档与稳定性

存档完全保存在本机：

```text
%APPDATA%\DeepDeskMiner
```

主要机制包括：

- 每 5 秒自动保存；装备与技能点等关键奖励立即保存；
- 原子写入、瞬时文件占用重试和备份存档；
- 单实例保护，避免两个版本同时读写同一份存档；
- 输入、挂机、悬浮、详情、存档和渲染分段诊断；
- 单次短暂异常自动恢复，存档写入失败不会暂停挖矿；
- 深层数值使用 64 位浮点计算，修复 500 层附近的整数重载问题。

需要从头开始时，请彻底退出游戏，再双击 `清空当前存档.cmd`，按提示键入 `CLEAR`。该工具只会删除上述目录内的当前 WPF 存档、备份和错误日志。

## 隐私设计

桌宠为了把物理输入转化为攻击，需要安装进程内的全局键盘与鼠标监听。监听层只向游戏逻辑传递 `keyboard` 或 `mouse` 两种匿名计数，不保存、传输或分析：

- 字符、键码或输入文字；
- 鼠标坐标、点击目标或浏览内容；
- 前台应用、窗口标题或文件；
- 剪贴板、屏幕截图、摄像头或麦克风。

暂停后监听仍驻留在当前游戏进程中，但会停止生成和处理输入事件；退出后完全卸载。游戏不包含账号、联网服务、广告、遥测或云存档。更完整说明见 [`docs/PRIVACY.md`](docs/PRIVACY.md)。

## 项目结构

这是一个面向持续扩展的可配置模块化单体：

```text
桌宠矿工/
├─ config/          宠物、技能、套装、掉率与数值曲线
├─ domain/          不依赖界面和文件系统的纯游戏规则
├─ app/             技能、换装、奖励等用例编排
├─ infra/           存档迁移、原子保存、备份与诊断
├─ ui/              桌宠 HUD、冒险手册和弹窗 XAML
├─ assets/          原创仓鼠、矿物与宝箱透明贴图
├─ deepdesk/        用于快速数值回归的 Python 纯逻辑原型
├─ tests/           架构、规则、迁移与界面冒烟测试
├─ launcher/        便携版与单文件版 Windows 启动器源码
├─ DeepDesk.ps1     Windows 输入、状态和模块组合入口
└─ ARCHITECTURE.md  扩展规则、模块边界与存档演进说明
```

新增宠物、技能、装备、套装或调整数值时，优先修改 `config/`，并通过领域层规则和自动化测试验证，避免把业务规则继续堆入界面事件。

## 开发与自检

在 Windows PowerShell 5.1 中运行完整自检：

```powershell
.\自检.ps1
```

自检涵盖旧存档迁移、真实 WPF XAML 加载、游戏规则、奖励即时保存与连续原子写入。安装 Python 的开发环境还可以运行：

```powershell
python -m unittest discover -s tests -v
```

这部分用于验证模块边界与纯逻辑原型；玩家运行游戏不依赖 Python。

## 常见问题

**启动后没有看到主面板？**

桌宠默认出现在桌面右下角，并会根据分辨率和 DPI 自动缩放、纠正到屏幕内。点击桌宠上的矿井战报，或从通知区域菜单打开冒险手册。

**关闭冒险手册后游戏为什么还在？**

这是桌宠的预期行为。请从通知区域菜单或冒险手册“档案”页选择退出。

**为什么矿物金币没有立刻增加？**

矿物与宠物在返回地面时统一结算；装备与技能点会立即进入永久存档。

**为什么不能手动装备？**

背包负责查看、筛选与比较；每次返回地面后系统会自动穿上每个部位属性最高的装备。

**为什么重新经过 70 层没有技能点？**

每个 70 层里程碑只在历史首次抵达时奖励一次。

**能在 macOS 或 Linux 上运行吗？**

当前版本依赖 Windows PowerShell 5.1、WPF 与 Windows 全局输入 API，只支持 Windows。
