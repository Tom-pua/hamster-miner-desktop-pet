# 桌宠矿工隐私说明

最后更新：2026-09-14

桌宠矿工是一款离线 Windows 桌面游戏。它不要求注册账号，不包含广告、遥测、云存档或在线分析服务，也不会主动把玩家数据发送到开发者或第三方服务器。

## 为什么需要监听键盘和鼠标

游戏的核心玩法是把日常物理输入转化为挖矿攻击。因此，运行期间会在游戏进程内安装 Windows 全局键盘和鼠标监听。

监听层只向游戏逻辑传递以下两类匿名事件：

- `keyboard`：发生了一次有效的物理键盘按下；
- `mouse`：发生了一次有效的物理鼠标按下。

长按产生的系统重复事件和程序注入事件不会被计入。

## 不收集的内容

游戏不会保存、传输或分析：

- 具体字符、键码、组合键或输入文字；
- 密码、聊天内容或表单内容；
- 鼠标坐标、点击目标或浏览历史；
- 前台应用名称、窗口标题、文件名或文件内容；
- 剪贴板、屏幕截图、摄像头、麦克风或定位数据；
- 设备标识、广告标识或使用统计。

暂停游戏后，全局监听仍驻留在当前游戏进程中，以便继续游戏时恢复，但会停止生成和处理输入事件。退出游戏后监听会完全卸载。

## 本地数据

游戏进度和诊断文件保存在：

```text
%APPDATA%\DeepDeskMiner
```

该目录可能包含当前存档、备份存档和本地错误日志。它们只用于恢复游戏进度与诊断运行异常。单文件版还会把程序资源释放到：

```text
%LOCALAPPDATA%\DeepDeskMiner\App\Build12
```

这些文件都不会由游戏自动上传。

## 删除数据

彻底退出游戏后，可运行项目附带的 `清空当前存档.cmd`，按提示键入 `CLEAR`，删除当前 WPF 存档、备份和错误日志。也可以手动删除 `%APPDATA%\DeepDeskMiner`。

单文件版释放出的程序文件可通过删除 `%LOCALAPPDATA%\DeepDeskMiner\App\Build12` 移除；这不会自动删除存档。

矿工档案页默认开启“开机后自动启动”。该选项只会在当前 Windows 用户的 `HKCU\Software\Microsoft\Windows\CurrentVersion\Run` 中保存启动命令，不包含游戏进度或输入数据；取消勾选会立即删除该启动项。

## 网络行为

当前游戏版本没有联网功能。GitHub Release 下载由 GitHub 提供，下载过程适用 GitHub 自身的隐私政策；游戏启动后不会连接 GitHub 检查更新。
